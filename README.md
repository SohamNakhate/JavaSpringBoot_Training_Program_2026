# Java Spring Boot Training Program 2026

A comprehensive collection of Java, Spring Boot, Microservices, React, JUnit, and Full Stack practice projects developed during the **Summer 2026 Training Program**.

This repository contains multiple backend and frontend projects covering:

* Spring Boot REST APIs
* Microservices Architecture
* JWT Authentication
* JPA & MySQL Integration
* React Frontend Applications
* Docker Basics
* Eureka Server
* JUnit Testing
* Maven & Gradle Projects
* Full Stack Development

# Getting Started

## Clone Repository

```bash
git clone https://github.com/SohamNakhate/JavaSpringBoot_Training_Program_2026.git
```

---

# Running Spring Boot Projects

```bash
cd project-folder
mvn spring-boot:run
```

OR

```bash
./mvnw spring-boot:run
```

---

# Running React Projects

```bash
cd react-project-folder
npm install
npm run dev
```
